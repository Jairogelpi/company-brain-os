# Historical implementation plans

The material under `docs/superpowers/` is an **implementation-history archive**. It records dated plans and design reasoning from earlier phases and may intentionally mention superseded architecture, framework versions or incomplete work that has since been resolved.

It is not part of the current product contract and is not normative documentation.

For current behavior use, in order:

1. executable code and migrations under `web/`
2. `docs/product/COMPANY_BRAIN_OS_V4.md`
3. `docs/architecture/`
4. `docs/security/` and `SECURITY.md`
5. `docs/RELEASE_SCORECARD.md`

Do not update historical plans merely to match the present stack. If an old plan conflicts with current documentation, the old plan is historical evidence, not documentation debt.
