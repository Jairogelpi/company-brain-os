# Company Brain OS v1.0.0-pilot

`v1.0.0-pilot` is the first formal repository release for production-pilot evaluation.

It certifies repository-controlled engineering readiness only. It does **not** certify product-market fit, customer ROI, legal approval, achieved production RTO/RPO, or independent penetration-test results.

## Product baseline

- governed assertion/evidence ledger as canonical truth
- deterministic, rebuildable graph projection with provenance
- explainable continuity-risk engine
- mitigation missions with artifact, competency, access and evidence checks
- independent transfer approval and explicit self-review rejection
- simulator, succession, knowledge assistant and executive metrics

## SaaS and security baseline

- organization-scoped authorization and PostgreSQL RLS
- composite tenant foreign keys and least-privilege runtime role
- secure invitation and User→Person identity workflows
- tenant-partitioned uploads, content validation, hashing and ClamAV
- durable worker/outbox flows and bounded retries
- dependency vulnerability gate and CodeQL static analysis

## Verification baseline

- deterministic clean install
- repository lint and formatting-policy checks
- real PostgreSQL migrations and explicit test seed
- full Vitest suite
- canonical Pedro → Laura executable acceptance journey
- critical-domain coverage gate
- PostgreSQL tenant-isolation gate
- strict TypeScript
- production Next.js build
- Chromium Playwright browser journeys for authentication and protected navigation
- production dependency audit

## External validation still required

The following are intentionally outside this release claim and remain tracked as external gates:

- qualified buyer evidence
- signed/paid pilot
- real customer baseline and post-pilot outcomes
- timed restore drill in target infrastructure
- deployment-specific legal review
- independent penetration test/certification and remediation evidence

See `docs/RELEASE_SCORECARD.md` and issue #14 for the evidence boundary.
