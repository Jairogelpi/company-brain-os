# Historical documentation archive

Files in this directory are retained for design history and traceability. They are **not** the accepted product contract and must not override current implementation, migrations, security controls or `docs/product/COMPANY_BRAIN_OS_V4.md`.

Use historical material to understand why the product evolved, not to determine current behavior.

## Archived material

- `PRODUCT_COMPLETION_R0_R4.md` — completion snapshot for the R0–R4 foundation.
- `UNIVERSAL_INTERVIEW_ENGINE_F0_5.md` — early adaptive-interview design hypothesis and test ideas.

The former pre-v4 graph-as-truth specification is intentionally represented by the root `COMPANY_BRAIN_OS_SPEC.md` compatibility pointer because old links may still target that path. The pointer directs readers to the accepted v4 contract and current architecture.
