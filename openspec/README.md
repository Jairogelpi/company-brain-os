# OpenSpec archive

This directory contains **historical design proposals, exploration notes and implementation plans** created during earlier development phases.

It is retained for decision traceability only. It is **not** a current source of truth and must not be used to infer the present stack, product contract, security posture or release status.

## Canonical sources

Use these instead:

1. `web/` executable code and database migrations
2. `docs/product/COMPANY_BRAIN_OS_V4.md` for the accepted product contract
3. `docs/architecture/` for current architecture
4. `docs/security/` and `SECURITY.md` for current security guarantees
5. `docs/RELEASE_SCORECARD.md` for evidence and claim status

Historical references such as older Next.js versions, superseded implementation plans or completed change proposals are expected in this directory and should not be "updated" to look current; preserving their original state is part of the audit trail.

New product requirements should be documented in the canonical product/architecture documentation or a clearly dated new proposal, not by silently rewriting archived proposals.
